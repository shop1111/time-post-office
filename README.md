# 📮 时光邮局 · 小局陪你记住生活

> 两件事：**胶囊**和**邮件**。
> 把生活的点滴放进胶囊——一张照片、一段语音、几行文字，邮局局长**小局**会问问你那天的故事，慢慢记住你。
> 写信给某个瞬间帮过你的人、平行时空的自己，TA 会在一天之内回信（由 agent 以 TA 的身份代笔）；写给未来的自己，到了那天由真实的你收到。

## 它能做什么

| 场景 | 体验 |
| --- | --- |
| 📷 寄一张旅行照片 | 自动读取 EXIF 拍摄时间与 GPS（离线逆地理编码出「洱海」），视觉模型看图，然后 AI 像朋友一样追问：那天和谁一起？按下快门时在想什么？ |
| 🔗 AI 会「想起」 | 追问时实时检索相关旧记忆，「这让我想起 8 月 9 日你说过……」，并展示检索打分 |
| 🗂️ 记忆抽取 | 一段记录 → 事件 / 人物 / 地点 / 计划 / 心愿 / 喜好，带重要度和到期日；用户可以一键「忘掉」 |
| 🎞️ 故事卡片 | 每天自动写成一张小说片段式卡片，四种模板（明信片 / 胶片 / 信纸 / 夜空），可导出图片 |
| 📅 月度回忆 | 情绪天气曲线、高光时刻、常出现的人和地方、一段月度叙事，可导出分享长图 |
| ✉️ 写信 · 代笔回信 | 写给帮过你的小明，几小时到一天后收到「小明」的回信：agent 先推理小明知道什么，只用他知道的事写信 |
| 🪐 平行时空的自己 | 选一个过去的分岔点，问「当时如果选了另一条路，你现在在干什么」；TA 只记得分岔点之前的事 |
| 💌 写给未来的自己 | 选一个未来的日子送达，到那天由真实的你收到，agent 不代写 |
| 📮 小局来信 | 邮局局长小局：旅行满三个月来回顾，考试到期来问结果，一周情绪低落来安慰，隔几天随手问候 |
| 🧠 记忆 | 小局眼中的你（画像）、文风指纹、人物地点关系图谱，通过「记忆管理」更正或撤回记忆 |
| 🕰️ 真实时间线 | 今天就是今天；胶囊、那个瞬间、分岔点只能选已经发生的时间 |

## 技术亮点

### 1. 分层记忆系统
```
原始记录 ──LLM 结构化抽取(zod 校验+修复重试)──▶ 记忆(重要度/到期日)
   │                                              │
   └─ EXIF / 视觉描述 / 语音转写                    ├─▶ 向量（SQLite BLOB）
                                                  ├─▶ 实体图谱（人物/地点/主题，去重合并）
                                                  └─▶ 用户画像 + 文风指纹（持续演化）
```
检索参考 Generative Agents，四路加权 + MMR 去重（`src/lib/memory/rank.ts`）：

```
score = 1.0·语义相似 + 0.35·0.5^(Δt/45天) + 0.45·重要度 + 0.5·实体重合
```
回顾往事时切换为「怀旧权重」（弱化新近性、强化重要度）。每次被想起会记录 `recallCount`。

### 2. 小局的信箱（`src/lib/postman/`）
每次打开页面检查一次：投递到期的信 → 代笔回信 → 小局的触发器候选 → 优先级排序 → 频控（20h）→ 去重键 → 检索记忆 → 写信 → 事实自检 → 投递

| 小局来信的触发器 | 条件 |
| --- | --- |
| 回顾往事 | 重要胶囊满 30 / 90 / 180 / 365 天 |
| 惦记的事 | 计划、考试到期且未回答（回信即闭环，标记已解决） |
| 情绪关怀 | 近 7 天情绪均值 < -0.25（并找回一段明亮的旧记忆） |
| 里程碑 | 胶囊数达标、某人出现 ≥4 次 |
| 随手问候 | 距上一封满 3 天，随机挑一颗最近的胶囊或一封你寄出的信 |

**代笔回信**（`src/lib/postman/reply.ts`）：寄给虚拟收件人的信，在随机 2~24 小时后由 agent 代笔回信。
- 某个人：检索候选记忆 → 以 TA 的身份逐条推理「TA 会不会知道」（Mock 下用规则：TA 在场 / 信里讲过）→ 只用 TA 知道的事和往来信件写信 → 越界核查改写。「为什么」面板列出「TA 知道的事」和「判断 TA 不知道的事」。
- 平行时空的自己：只检索分岔点之前的记忆 + 文风指纹，分岔之后的人生是想象，但要和往来信件一致。
- 写给未来的自己：不代写，到日子投递。

### 3. 角色真实感 & 不编造
- **知识边界**：代笔的「小明」只知道你们之间的信、那个瞬间，以及推理后判断他本来就会知道的事。
- **文风指纹**（`src/lib/memory/style.ts`）：本地统计句长、口头禅、句尾语气词、标点习惯、代表性原句，让平行时空的你写信时像你本人。
- **时间一致性**：平行时空的你只能检索到分岔点之前的记忆；所有时间都是真实时间，胶囊和分岔点不能选未来。
- **事实自检**：引用的记忆 id 强校验；接入真实模型时再做一轮「无依据说法」核查并自动改写。
- **可解释**：每封信都附「为什么收到这封信」+ 引用的真实回忆，可点回原记录。

### 4. 可插拔模型 & 优雅降级
按角色配置，全部走 OpenAI 兼容协议（`src/lib/ai/provider.ts`）：

| 角色 | 默认 | 未配置时 |
| --- | --- | --- |
| CHAT 对话/写信/代笔/抽取 | DeepSeek `deepseek-flash`（可选 `deepseek-v4-pro`，支持思考模式） | Mock 演示模式：规则抽取器 + 模板写信器 + 文风指纹 |
| VISION 看图 | 通义 Qwen-VL / 硅基流动 Qwen2.5-VL | EXIF + 用户文字兜底 |
| EMBED 向量 | 本地 lite（中文 n-gram 哈希向量，零依赖） | — 可切 `api` 用 bge-m3 |
| ASR 语音 | 浏览器 Web Speech 实时转写 | 可选 SenseVoice 服务端转写 |

任何一次远程调用失败都会回退到本地实现，演示现场不怕断网。

### 5. 工程
Next.js 15 App Router 全栈 · TypeScript strict · Prisma + SQLite · SSE 流式输出 · 前端图片压缩 · framer-motion 动效 · recharts · react-force-graph · html-to-image · vitest 单测（检索打分 / 触发器 / 规则抽取 / 文风指纹 / JSON 修复）

## 快速开始

```bash
npm install
cp .env.example .env      # 不填 Key 也能跑（Mock 演示模式）
npx prisma db push
npm run seed              # 可选：导入示例数据（林小满的半年），也可以在设置页点「导入示例数据」
npm run dev
```

打开 http://localhost:3000 。

接入 DeepSeek：在 `.env` 中填 `CHAT_API_KEY`，重启即可。DeepSeek 当前的 `deepseek-flash` 支持图片理解（[官方能力表](https://api-docs.deepseek.com/quick_start/pricing/)），本项目仍按角色独立配置，看图请设置 `VISION_*`（见 `.env.example`）。

```bash
npm test          # 单元测试
npm run build     # 生产构建
```

## 3 分钟演示脚本

1. **设置 → 导入示例数据**：林小满，在杭州做设计师的半年。回到主页，小局注意到她最近一周情绪低落，送来一封问候信；半年前写给未来自己的信今天送达 → 拆信，展开「为什么收到这封信」。
2. **设置 → 演示工具 → 回信立即送达**，然后去 **邮件**：小满昨晚写给小鹿的信正在等回信，刷新一下就能收到。展开「为什么」，能看到小局判断小鹿知道哪些事、不知道哪些事。
3. **邮件 → 收件人 → 新收件人**：加一个「某个瞬间帮过你的人」，写信给 TA；再加一个「平行时空的自己」，问问 TA 当时如果做了另一个选择现在在干什么。
4. **回信给小局**：之后几天，小局会来问认证考试的结果，回信后计划被标记为已解决，回信本身也成为新的记忆。
5. **放一颗照片胶囊**：EXIF 自动填时间地点（不能选未来）→ 小局追问并「想起」旧记忆 → 收进邮局，看到抽取的记忆和故事卡片。
6. **胶囊 → 月度回忆**：情绪天气、高光时刻，导出分享长图。
