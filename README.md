# 📮 时光邮局 · 小局陪你记住生活

> 两件事：**胶囊**和**邮件**，中间站着邮局局长**小局**。
>
> 把生活的点滴放进胶囊——一张照片、一段语音、几行文字，小局会问问你那天的故事，慢慢记住你。
> 写信给某个瞬间帮过你的人、平行时空的自己，TA 会在一天之内回信（由 agent 以 TA 的身份代笔）；写给未来的自己，到了那天由真实的你收到。
> 没事的时候，也可以去柜台和小局聊聊。

不填任何 API Key 也能完整跑通（本地演示模式）；填上 DeepSeek 的 Key，就是真实模型。

## 快速开始

```bash
npm install
cp .env.example .env      # 不填 Key 也能跑（本地演示模式）
npx prisma db push
npm run dev
```

打开 http://localhost:3000 ，在首页或 **设置 → 示例数据** 点「导入示例数据」，就能看到「林小满在杭州的半年」。也可以用 `npm run seed` 从命令行导入。

接入真实模型：在 `.env` 里填 `CHAT_API_KEY`（DeepSeek），重启即可。看图、向量、语音各自独立配置，见 [.env.example](.env.example)。本地开发时把 `ENABLE_LOCAL_MODEL_SETTINGS` 设为 `1`，可以直接在设置页临时切换模型（重启后恢复，公开部署请保持关闭）。

```bash
npm test               # 单元测试（vitest）
npm run lint
npm run build          # 生产构建
npm run eval:curator   # 小局对话评测（需要真实 Key，加 -- --baseline 对比旧版提示词）
```

演示流程见 [docs/DEMO.md](docs/DEMO.md)。

## 页面一览

导航：**主页 / 胶囊 / 邮件 / 小局 / 记忆**，另有设置页和「它是怎么工作的」架构页（`/about`）。

| 页面 | 能做什么 |
| --- | --- |
| 🏠 主页 | 最新一封未拆的信是首屏主角，旁边是「放一颗胶囊」「写一封信」；下方是最近的故事卡片和「小局眼中的你」 |
| 📦 胶囊 | 照片 / 语音 / 文字三种胶囊。照片自动读 EXIF 时间和 GPS（离线逆地理编码出「洱海」），小局追问 2~4 轮并「想起」旧记忆，收进邮局时显示真实阶段进度；列表按月分组，可按人物 / 地点标签筛选 |
| 🎞️ 故事卡片 | 每颗胶囊整理好后写成一张小说片段式卡片，四种模板（明信片 / 胶片 / 信纸 / 夜空），可导出图片 |
| 📅 月度回忆 | 情绪天气曲线、高光时刻、常出现的人和地方、一段月度叙事，可导出分享长图 |
| ✉️ 邮件 | 收件箱（未拆 / 已拆）、寄出的信、收件人；每位收件人有往来信件串 |
| 💬 小局 | 「和小局聊聊」：胶囊之外随时闲聊，小局会参考你的记忆接话；历史保存在本地，可清空 |
| 🧠 记忆 | 小局眼中的你（画像）、文风指纹、**记忆地图**（人物 / 地点 / 经历 / 兴趣与偏好 / 计划与目标 / 重要事实），点进分类看详情和相关胶囊；**记忆管理**里更正或撤回任何一条记忆 |
| ⚙️ 设置 | 称呼、模型状态、导入 / 清空示例数据、导出 JSON、演示工具（回信立即送达、让小局现在写一封信） |

时间一律是真实的今天：胶囊时间、「那个瞬间」、分岔点只能选过去，写给未来的信只能送往未来，前后端都校验。

## 收件人与回信

| 收件人 | 回信方式 |
| --- | --- |
| 某个人（某个瞬间帮过你的人） | 2~24 小时后由 agent 以 TA 的身份代笔：先检索候选记忆，逐条推理「TA 会不会知道」，只用 TA 知道的事写信，再做越界核查。「为什么」面板列出 TA 知道 / 不知道的事 |
| 平行时空的自己 | 只能检索到分岔点之前的记忆，配合你的文风指纹写信；分岔之后的人生是想象，但和往来信件保持一致 |
| 未来的自己 | 不代写，到日子由真实的你收到；没到日子信封是封着的 |
| 小局 | 回信给小局「惦记的事」，对应的计划会被标记为已解决；你写的每封信也会成为记忆 |

**小局的主动来信**（`src/lib/postman/`）：每次打开页面检查一次 → 触发器候选 → 优先级 → 20 小时频控 → 去重键 → 检索 → 写信 → 事实自检 / AI 腔检查 → 投递。

| 触发器 | 条件 |
| --- | --- |
| 回顾往事 | 重要胶囊满 30 / 90 / 180 / 365 天 |
| 惦记的事 | 计划、考试到期且未回答 |
| 情绪关怀 | 近 7 天情绪均值 < -0.25（同时找回一段明亮的旧记忆） |
| 里程碑 | 胶囊数达标、某人出现 ≥ 4 次 |
| 随手问候 | 距上一封满 3 天，随机挑一颗最近的胶囊或一封你寄出的信 |

每封信都附「为什么收到这封信」和引用的真实回忆，可以点回原胶囊。

## 技术亮点

### 1. 分层记忆与混合检索

```
原始胶囊 ──LLM 结构化抽取(zod 校验 + 修复重试)──▶ 记忆(类型 / 重要度 / 到期日 / 版本)
   │                                               ├─▶ 向量（SQLite BLOB）
   └─ EXIF / 视觉描述 / 语音转写                     ├─▶ 实体（人物 / 地点 / 主题，去重合并）→ 记忆地图
                                                   └─▶ 用户画像 + 文风指纹（持续演化）
```

检索参考 Generative Agents，四路加权 + MMR 去重（`src/lib/memory/rank.ts`）：

```
score = 1.0·语义相似 + 0.35·0.5^(Δt/45天) + 0.45·重要度 + 0.5·实体重合
```

回顾往事时切换为「怀旧权重」（弱化新近性、强化重要度），每次被想起累计 `recallCount`。

### 2. 记忆可控、派生数据一致

- 更正带乐观锁（`expectedRevision`），撤回是软撤回：原始胶囊和历史信件保留，但撤回的记忆不再被检索、写信、画像使用。
- 任何记忆变更都会让画像、月度回忆失效（`invalidateDerived`），页面提示「画像待更新」；生成期间发生变更时拒绝保存旧结果。
- 详见 [docs/MEMORY_CONTROL.md](docs/MEMORY_CONTROL.md)、[docs/MEMORY_CONSISTENCY.md](docs/MEMORY_CONSISTENCY.md)。

### 3. 小局：人设、对话策略与防御层（`src/lib/curator/`）

- **人设与世界**：小局有自己的邮局（猫「邮票」、档案柜、炉子……），按二十四节气、季节和时段决定「邮局今天的样子」；和你的关系分初识 / 熟悉 / 老友三个阶段；小局说过的关于自己的细节会存成自我记忆，前后不矛盾。
- **对话策略**：先判断你上一句的长短、情绪、投入程度，再选动作（注意到 / 追问 / 接话 / 回答 / 安慰 / 收尾 / 修正），轮数和长度随之变化；能听懂「嫌你话少」「像机器人」这类反馈。
- **AI 腔检测**：套话词表 + 句式规则，来信分数过高时改写一次。
- **防御层**：注入、套取设定、把小局当免费模型用（写代码 / 写作文 / 翻译）的消息在进入模型前就被拦下，不花 token；危机信号会附上求助热线；输出复述设定或报出模型名时整段替换。另有令牌桶限流。
- 详见 [docs/CURATOR.md](docs/CURATOR.md)。

### 4. 角色真实感 & 不编造

- **知识边界**：代笔的「小鹿」只知道你们之间的信、那个瞬间，以及推理后判断她本来就会知道的事。
- **时间一致性**：平行时空的你只能看到分岔点之前的记忆。
- **文风指纹**（`src/lib/memory/style.ts`）：本地统计句长、口头禅、句尾语气词、标点习惯、代表性原句。
- **事实自检**：引用的记忆 id 强校验；接入真实模型时再做一轮「无依据说法」核查并自动改写。

### 5. 可插拔模型 & 优雅降级

按角色配置，全部走 OpenAI 兼容协议（`src/lib/ai/provider.ts`），带超时、并发上限、重试退避：

| 角色 | 默认 | 未配置 / 失败时 |
| --- | --- | --- |
| CHAT 追问 / 闲聊 / 写信 / 代笔 / 抽取 | DeepSeek `deepseek-flash`（可选 `deepseek-v4-pro`，支持思考模式） | 规则抽取器 + 模板写信器 + 文风指纹 |
| VISION 看图 | DeepSeek Flash / 通义 Qwen-VL / 硅基流动 Qwen2.5-VL | EXIF + 用户文字 |
| EMBED 向量 | 本地 lite（中文 n-gram 哈希向量，零依赖） | 可切 `api` 用 bge-m3 |
| ASR 语音 | 浏览器 Web Speech 实时转写 | 可选 SenseVoice 服务端转写 |

界面上每一步都标着「真实模型 / 本地演示 / 已降级 / 防御层」，数据来自后端实际执行情况；演示现场断网也不会白屏。

### 6. 工程

Next.js 15 App Router 全栈 · React 19 · TypeScript strict · Prisma + SQLite · SSE 流式输出（可中断、可重试、刷新后接着上次的进度） · 前端图片压缩 · Tailwind CSS 4 · framer-motion · recharts · html-to-image · vitest（13 个测试文件，覆盖检索打分、触发器、代笔回信、小局策略与防御、记忆更正 / 撤回、记忆地图、SSE、时间规则等）
