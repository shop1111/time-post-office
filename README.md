# 📮 时光邮局 · 会记住你生活的 AI 伙伴

> 把生活寄存在这里——一张照片、一段语音、几行日记。
> 邮差会好奇地问你那天发生了什么，慢慢记住你的故事，
> 然后在未来的某一天，替**过去的你**、**未来的你**给你写一封信。

## 它能做什么

| 场景 | 体验 |
| --- | --- |
| 📷 寄一张旅行照片 | 自动读取 EXIF 拍摄时间与 GPS（离线逆地理编码出「洱海」），视觉模型看图，然后 AI 像朋友一样追问：那天和谁一起？按下快门时在想什么？ |
| 🔗 AI 会「想起」 | 追问时实时检索相关旧记忆，「这让我想起 8 月 9 日你说过……」；点开能看到语义 / 人物地点 / 重要程度 / 新近四项得分条 |
| 🗂️ 收进邮局 | 读懂这一天 → 生成向量 → 存进记忆库 → 更新画像 → 写故事卡片，五步逐个打勾、显示真实耗时；部分失败只重试那一步，刷新页面也能接上 |
| 🎞️ 故事卡片 | 每天自动写成一张小说片段式卡片，四种模板（明信片 / 胶片 / 信纸 / 夜空），可导出图片 |
| 📅 月度回忆 | 情绪天气曲线、高光时刻、常出现的人和地方、一段月度叙事，可导出分享长图 |
| ✉️ 主动来信 | 三个月后，「过去的你」来信回顾那次旅行；考试到期，「过去的你」来问结果；一周情绪低落，「未来的你」来安慰 |
| 💌 拆信 | 火漆 → 翻盖 → 抽出信纸 → 逐字浮现；核查徽章如实标「通过 / 改写过 / 未核查 / 未通过」；能找到原文的句子画虚线，点开看你当时写下的话 |
| 🔊 听信 | 语音日记的原声可回放、拖动进度；信件朗读优先用 TTS 真人音色，没配置就用浏览器朗读并逐句高亮 |
| 💌 时间胶囊 | 写给半年后、一年后自己的信，按期送达 |
| 🧠 记忆宫殿 | AI 眼中的你（画像）、文风指纹、人物地点关系图谱；记忆可以更正或撤回，撤回后不再被检索、写信和引用 |
| ⏩ 时光机 | 虚拟时钟快进，全屏过场里直播邮差引擎：每个候选逐条过闸，显示真实去向（已送达 / 已寄过 / 同类已写 / 名额用完 / 没写成）和每一步耗时 |
| 🩺 体检 | 设置页能看到每项 AI 能力是否配置、最近 30 次调用走的是真模型 / 本地演示 / 降级（带原因），一键测连通 |

## 技术亮点

### 1. 分层记忆系统
```
原始记录 ──LLM 结构化抽取(zod 校验+修复重试)──▶ 记忆(重要度/到期日)
   │                                              │
   └─ EXIF / 视觉描述 / 语音转写                    ├─▶ 向量（SQLite BLOB）
                                                  ├─▶ 实体图谱（人物/地点/主题，去重合并）
                                                  └─▶ 用户画像 + 文风指纹（持续演化）
```
检索参考 Generative Agents，四路加权 + MMR 去重（`src/lib/memory/rank.ts`）：

```
score = 1.0·语义相似 + 0.35·0.5^(Δt/45天) + 0.45·重要度 + 0.5·实体重合
```
回顾往事时切换为「怀旧权重」（弱化新近性、强化重要度）。每次被想起会记录 `recallCount`。

### 2. 邮差引擎（主动来信调度器）
`src/lib/postman/` — 快照 → 触发器候选 → 优先级排序 → 去重键 → 频控（20h）→ 同类型限一封 → 名额 → 检索记忆 → 模仿口吻写信 → 事实核查 → 投递

每个候选的去向和执行在同一个分支里决定，决定本身通过 SSE 实时推给前端（`POST /api/postman`，`Accept: text/event-stream`）。所有邮差动作进同一个进程内队列，连点快进不会重复写信；单封失败只标记这一封，不拖垮整轮。

| 触发器 | 条件 | 寄信人 |
| --- | --- | --- |
| 周年回顾 | 重要记录满 30 / 90 / 180 / 365 天 | 邮差 / 过去的你 |
| 未完结线索 | 计划、考试到期且未回答 | 过去的你（回信即闭环，标记已解决） |
| 情绪关怀 | 近 7 天情绪均值 < -0.25 | 未来的你（并找回一段明亮的旧记忆） |
| 里程碑 | 记录数达标、某人出现 ≥4 次 | 邮差 |
| 时间胶囊 | 用户设定的送达日 | 从前的你 |

### 3. 像本人的口吻 & 不编造
- **文风指纹**（`src/lib/memory/style.ts`）：本地统计句长、口头禅、句尾语气词、标点习惯、代表性原句，转为写作指令。
- **时间一致性**：「过去的你」的锚点、检索、文风样本和画像都截止到落款日当天。
- **事实核查如实记录**：核查 → 发现问题就改写 → 改写后再核查一次；结果存为 `checkStatus`（passed / rewritten / unchecked / failed），任何一步降级都不算通过。
- **逐句出处**：写信时在事务里把被引用记忆的原文快照存进信件；`GET /api/letters/{id}/sources` 用逐字比对把句子和原文对上，对不上的宁可不标。回忆后来被更正会提示，被撤回就不再显示原文。
- **可解释**：每封信都附「为什么收到这封信」+ 引用的真实回忆，可点回原记录。

### 4. 可插拔模型 & 优雅降级
按角色配置，全部走 OpenAI 兼容协议（`src/lib/ai/provider.ts`）：

| 角色 | 默认 | 未配置时 |
| --- | --- | --- |
| CHAT 对话/写信/抽取 | DeepSeek `deepseek-flash`（可选 `deepseek-v4-pro`，支持思考模式） | Mock 演示模式：规则抽取器 + 模板写信器 + 文风指纹 |
| VISION 看图 | 通义 Qwen-VL / 硅基流动 Qwen2.5-VL | EXIF + 用户文字兜底 |
| EMBED 向量 | 本地 lite（中文 n-gram 哈希向量，零依赖） | — 可切 `api` 用 bge-m3 |
| ASR 语音 | 浏览器 Web Speech 实时转写 | 可选 SenseVoice 服务端转写 |
| TTS 朗读 | 未配置 | 浏览器朗读（可配 OpenAI 兼容的 `/audio/speech`，如硅基流动 CosyVoice） |

远程调用有总超时、网络 / 429 / 5xx 有限退避重试、全局并发上限；失败时回退本地实现，并**如实标出降级原因**（超时、限流、Key 无效……），界面上每条 AI 结果都有「真实模型 / 本地演示 / 已降级」小标记。演示现场不怕断网。

### 5. 工程
Next.js 15 App Router 全栈 · TypeScript strict · Prisma + SQLite · SSE 流式输出（追问 / 收进邮局 / 邮差流水线）· 可恢复的后台任务（Job 检查点，断线不中断、重试只重做失败阶段）· framer-motion 动效 · recharts · react-force-graph · html-to-image · vitest 单测 270+ 项（检索打分 / 触发器 / 邮差决策 / 任务恢复 / 核查 / 出处 / 记忆一致性 / 文件 Range / TTS 缓存 …）

## 快速开始

```bash
npm install
cp .env.example .env      # 不填 Key 也能跑（Mock 演示模式）
npx prisma db push
npm run seed              # 可选：载入示例人生「林小满」
npm run dev
```

打开 http://localhost:3000 。

> 开发模式（`npm run dev`）每个页面第一次打开要现场编译，会慢几秒。演示请用正式模式：`npm run build && npm start`，每页只要几十毫秒。

接入 DeepSeek：在 `.env` 中填 `CHAT_API_KEY`，重启即可。DeepSeek 当前的 `deepseek-flash` 支持图片理解（[官方能力表](https://api-docs.deepseek.com/quick_start/pricing/)），本项目仍按角色独立配置，看图请设置 `VISION_*`（见 `.env.example`）。

```bash
npm test          # 单元测试
npm run build     # 生产构建

# 演示自检：按下面的演示脚本把整条链路跑一遍（会清空并重新载入示例数据，必须带 --yes）
npm run demo:check -- --yes             # 不配 Key 也能通过
npm run demo:check -- --yes --real --runs 3   # 要求聊天类调用都是真实模型（向量可用本地 lite）
```

## 3 分钟演示脚本

1. **设置 → 载入示例人生**：林小满，在杭州做设计师的半年。顺便看一眼「体检」：现在是真实模型还是本地演示。回到首页，邮差注意到她最近一周情绪低落，送来一封「未来的你」的信。
2. **拆信**：点火漆，看信纸抽出、正文逐字浮现；标题下的核查徽章说明这封信有没有被核查；点一句带虚线的话，看出处里她当时写下的原文；点「朗读这封信」。
3. **右上角时光机 → +7 天**：全屏过场里日期滚动，邮差引擎把每个候选逐条过闸——大理旅行满三个月写成回顾信、认证考试到期写成追问信，其他候选标出「已寄过 / 同类已写 / 名额用完」；最后信封飞进信箱。
4. **回信**：回复「还没考，推迟了」计划不会关；回复「考完了，过了」计划才关闭，回信本身也会走一遍收进邮局。
5. **寄一张照片**：EXIF 自动填时间地点 → AI 追问并「想起」旧记忆（点开看四项得分）→ 收进邮局，五步逐个打勾，看到抽取的记忆和故事卡片。
6. **时间线 → 8 月月度回忆**：情绪天气、高光时刻，导出分享长图。
7. **记忆宫殿**：AI 眼中的你、文风指纹、关系图谱；更正一条记错的记忆，或者撤回一条不想被记住的。

## 目录

```
src/lib/ai/          provider（可插拔模型）· transport（超时/重试/并发）· json（结构化输出修复）· speech（TTS）· telemetry（体检记录）· prompts · mock
src/lib/memory/      embed-lite · rank（检索打分+MMR）· retrieve · extract · heuristics · style · profile · consistency / manage（更正、撤回、派生数据失效）
src/lib/postman/     triggers（纯函数触发器）· engine（决策）· writer（写信四阶段）· check（核查）· history（落款日边界）· queue / actions（串行动作）
src/lib/letters/     snapshot（引用原文快照）· sources（逐句出处）· reply（回信判断）· speech（朗读缓存）
src/lib/jobs.ts      收进邮局的可恢复任务（五阶段、检查点、断线续跑）
src/lib/story.ts     故事卡片 & 月度回忆
scripts/             demo-check（演示自检）
src/lib/demo/        示例人生数据 & 程序生成的插画
src/app/             页面与 API 路由
tests/               vitest
```

数据全部存在本地 `data/app.db`，可在设置页一键导出 JSON。
