# 📮 时光邮局 · 会记住你生活的 AI 伙伴

> 把生活寄存在这里——一张照片、一段语音、几行日记。
> 邮差会好奇地问你那天发生了什么，慢慢记住你的故事，
> 然后在未来的某一天，替**过去的你**、**未来的你**给你写一封信。

## 它能做什么

| 场景 | 体验 |
| --- | --- |
| 📷 寄一张旅行照片 | 自动读取 EXIF 拍摄时间与 GPS（离线逆地理编码出「洱海」），视觉模型看图，然后 AI 像朋友一样追问：那天和谁一起？按下快门时在想什么？ |
| 🔗 AI 会「想起」 | 追问时实时检索相关旧记忆，「这让我想起 8 月 9 日你说过……」，并展示检索打分 |
| 🗂️ 记忆抽取 | 一段记录 → 事件 / 人物 / 地点 / 计划 / 心愿 / 喜好，带重要度和到期日；用户可以一键「忘掉」 |
| 🎞️ 故事卡片 | 每天自动写成一张小说片段式卡片，四种模板（明信片 / 胶片 / 信纸 / 夜空），可导出图片 |
| 📅 月度回忆 | 情绪天气曲线、高光时刻、常出现的人和地方、一段月度叙事，可导出分享长图 |
| ✉️ 主动来信 | 三个月后，「过去的你」来信回顾那次旅行；考试到期，「过去的你」来问结果；一周情绪低落，「未来的你」来安慰 |
| 💌 时间胶囊 | 写给半年后、一年后自己的信，按期送达 |
| 🧠 记忆宫殿 | AI 眼中的你（画像）、文风指纹、人物地点关系图谱、所有记忆可改可删 |
| ⏩ 时光机 | 虚拟时钟快进，几十秒内演示「几个月后」的来信 |

## 技术亮点

### 1. 分层记忆系统
```
原始记录 ──LLM 结构化抽取(zod 校验+修复重试)──▶ 记忆(重要度/到期日)
   │                                              │
   └─ EXIF / 视觉描述 / 语音转写                    ├─▶ 向量（SQLite BLOB）
                                                  ├─▶ 实体图谱（人物/地点/主题，去重合并）
                                                  └─▶ 用户画像 + 文风指纹（持续演化）
```
检索参考 Generative Agents，四路加权 + MMR 去重（`src/lib/memory/rank.ts`）：

```
score = 1.0·语义相似 + 0.35·0.5^(Δt/45天) + 0.45·重要度 + 0.5·实体重合
```
回顾往事时切换为「怀旧权重」（弱化新近性、强化重要度）。每次被想起会记录 `recallCount`。

### 2. 邮差引擎（主动来信调度器）
`src/lib/postman/` — 快照 → 触发器候选 → 优先级排序 → 频控（20h）→ 去重键 → 检索记忆 → 模仿口吻写信 → 事实自检 → 投递

| 触发器 | 条件 | 寄信人 |
| --- | --- | --- |
| 周年回顾 | 重要记录满 30 / 90 / 180 / 365 天 | 邮差 / 过去的你 |
| 未完结线索 | 计划、考试到期且未回答 | 过去的你（回信即闭环，标记已解决） |
| 情绪关怀 | 近 7 天情绪均值 < -0.25 | 未来的你（并找回一段明亮的旧记忆） |
| 里程碑 | 记录数达标、某人出现 ≥4 次 | 邮差 |
| 时间胶囊 | 用户设定的送达日 | 从前的你 |

### 3. 像本人的口吻 & 不编造
- **文风指纹**（`src/lib/memory/style.ts`）：本地统计句长、口头禅、句尾语气词、标点习惯、代表性原句，转为写作指令。
- **时间一致性**：「过去的你」只能检索到写信那天之前的记忆。
- **事实自检**：引用的记忆 id 强校验；接入真实模型时再做一轮「无依据说法」核查并自动改写。
- **可解释**：每封信都附「为什么收到这封信」+ 引用的真实回忆，可点回原记录。

### 4. 可插拔模型 & 优雅降级
按角色配置，全部走 OpenAI 兼容协议（`src/lib/ai/provider.ts`）：

| 角色 | 默认 | 未配置时 |
| --- | --- | --- |
| CHAT 对话/写信/抽取 | DeepSeek `deepseek-chat` | Mock 演示模式：规则抽取器 + 模板写信器 + 文风指纹 |
| VISION 看图 | 通义 Qwen-VL / 硅基流动 Qwen2.5-VL | EXIF + 用户文字兜底 |
| EMBED 向量 | 本地 lite（中文 n-gram 哈希向量，零依赖） | — 可切 `api` 用 bge-m3 |
| ASR 语音 | 浏览器 Web Speech 实时转写 | 可选 SenseVoice 服务端转写 |

任何一次远程调用失败都会回退到本地实现，演示现场不怕断网。

### 5. 工程
Next.js 15 App Router 全栈 · TypeScript strict · Prisma + SQLite · SSE 流式输出 · 前端图片压缩 · framer-motion 动效 · recharts · react-force-graph · html-to-image · vitest 单测（检索打分 / 触发器 / 规则抽取 / 文风指纹 / JSON 修复）

## 快速开始

```bash
npm install
cp .env.example .env      # 不填 Key 也能跑（Mock 演示模式）
npx prisma db push
npm run seed              # 可选：载入示例人生「林小满」
npm run dev
```

打开 http://localhost:3000 。

接入 DeepSeek：在 `.env` 中填 `CHAT_API_KEY`，重启即可。DeepSeek 官方 API 不支持图片，如需看图请另外配置 `VISION_*`（见 `.env.example`）。

```bash
npm test          # 单元测试
npm run build     # 生产构建
```

## 3 分钟演示脚本

1. **设置 → 载入示例人生**：林小满，在杭州做设计师的半年。回到首页，邮差注意到她最近一周情绪低落，送来一封「未来的你」的信 → 拆信，展开「为什么收到这封信」。
2. **右上角时光机 → +7 天**：大理旅行满三个月，「过去的你」寄来回顾信；认证考试到期，「过去的你」来问结果；半年前写的时间胶囊送达。面板里能看到邮差引擎的候选与优先级。
3. **回信**：回复考试结果 → 计划被标记为已解决，回信本身成为新的记忆。
4. **寄一张照片**：EXIF 自动填时间地点 → AI 追问并「想起」旧记忆（悬停可看检索打分）→ 收进邮局，看到抽取的记忆和故事卡片。
5. **时间线 → 8 月月度回忆**：情绪天气、高光时刻，导出分享长图。
6. **记忆宫殿**：AI 眼中的你、文风指纹、关系图谱，改一条记错的记忆。
