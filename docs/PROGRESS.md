## 一、项目概述

「时光邮局」是一个会记住你生活的 AI 伙伴，业务分两条线：
- **胶囊**：用照片、语音、文字记录生活的点滴。邮局局长「小局」会追问补全当天的经历，形成长期记忆，并生成故事卡片、月度回忆。
- **邮件**：写给有具体收件人的信。
  - 写给某个人（比如某个瞬间帮过你的小明）或平行时空的自己：几小时到一天后，由 agent 以收件人的身份代笔回信。
  - 写给未来的自己：到日子由真实的你收到。
  - 小局会根据胶囊和信件主动来信问候、安慰。

时间一律是真实的今天；胶囊、那个瞬间、分岔点只能选过去的时间。

**核心闭环：** 胶囊 → 小局追问 → 记忆抽取 → 长期记忆 / 画像 → 小局来信 / 代笔回信 → 用户回信 → 回信再成为记忆

### 2026-11-04 业务重构
- 术语统一：柜台 → 主页；记录 / 时间线 → 胶囊；信箱 → 邮件；时光邮差 → 小局；往日回响 → 以前的今天；时间胶囊（写给未来）→ 写给未来的自己。
- 导航改为 主页 / 胶囊 / 邮件 / 记忆，旧网址自动重定向（`next.config.ts`）。
- 删除时光机（虚拟时钟）。胶囊时间、那个瞬间、分岔点前后端都校验只能是过去（`src/lib/time-rules.ts`）。
- 取消 agent 扮演「过去的你 / 未来的你」，小局的触发器全部以小局身份写信，新增「随手问候」触发器。
- 新增收件人（`Correspondent`）和代笔回信引擎（`src/lib/postman/reply.ts`）：
  - 写给某个人：先检索，再推理 TA 知道什么，只用 TA 知道的事写信。
  - 写给平行时空的自己：只能看到分岔点之前的记忆。
- 设置页新增演示工具：「回信立即送达」和「让小局现在写一封信」。

## 三、功能列表

### 1. 生活记录
- **照片**：点击或拖拽上传；自动读取 EXIF 拍摄时间与 GPS；GPS 离线解析为城市 / 景点（如「洱海」）；大图前端压缩到长边 1600px；配置视觉模型后自动生成画面描述
- **语音**：MediaRecorder 录音 + 实时音频波形；Web Speech API 边说边转文字；可选服务端转写
- **日记**：自由文本，可补充时间、地点

### 2. AI 追问
- 寄出记录后，AI 像朋友一样追问 2~3 轮（谁、在哪、那一刻的感受、为什么重要）
- 流式逐字输出
- 追问前先检索相关旧记忆，自然提起「这让我想起 X 月 X 日你说过……」，并在界面上展示联想到的记忆及其检索得分
- 支持随时「就聊到这」提前结束

### 3. 记忆系统
- 一条记录自动抽取 2~6 条结构化记忆：经历 / 事实 / 人物 / 地点 / 心愿 / 计划 / 喜好
- 每条记忆带重要度（1~10），计划类带到期日（如「下周考试」→ 自动推算日期）
- 自动识别情绪效价与情绪词
- 记忆完成后展示「我记住了」，用户可点 × 让 AI 忘掉某条
- 人物、地点、主题自动合并成实体图谱
- 用户画像（AI 眼中的你）随记录持续更新

### 4. 小局来信（主动来信）
| 触发器 | 条件 |
| --- | --- |
| 回顾往事 | 重要胶囊 / 照片满 30、90、180、365 天 |
| 惦记的事 | 计划、考试到期且未被回答 |
| 情绪关怀 | 近 7 天情绪均值偏低（同时找回一段明亮的旧记忆） |
| 里程碑 | 胶囊数达标；某个人出现 ≥ 4 次 |
| 随手问候 | 距上一封满 3 天，随机挑一颗最近的胶囊或一封你寄出的信 |

- 寄信人都是小局本人。
- 每封信可展开「为什么收到这封信」，列出触发原因与引用的真实回忆，可点回原胶囊。
- 打开页面时自动检查一次信箱；设置页的演示工具可以让小局立即写一封。

### 5. 邮件
- 三个分区：收件箱（别人写给你的信）、寄出的信（含回信状态）、收件人；每位收件人都有往来信件串。
- 收件人类型：
  - 某个人：需要填那个瞬间，日期只能选过去。
  - 平行时空的自己：需要填分岔点和「当时如果……」。
  - 未来的自己、小局：固定收件人。
- 代笔回信：在随机 2~24 小时后送达，设置里可以打开「回信立即送达」。
  - 某个人：只用 TA 会知道的事写信，「为什么」面板列出 TA 知道 / 不知道的事。
  - 平行时空的自己：只记得分岔点之前的事。
- 写给未来的自己：可选一个月、半年、一年、三年后，或自定义日期；没到日子信封是封着的。
- 你写的信也会进入记忆。回复小局「惦记的事」类来信，会把对应计划标记为已解决。

### 6. 故事卡片
- 每条记录完成后自动生成：标题 + 120~180 字小说片段 + 一句金句
- 四种模板按内容自动选择：明信片（照片）、胶片（高兴）、信纸（日常）、夜空（低落 / 深夜）
- 一键导出 PNG，可重新生成

### 7. 胶囊列表与月度回忆
- 胶囊列表：按月瀑布流，人物 / 地点标签筛选，每月一条情绪色条
- 月度回忆：标题与关键词、记录统计、情绪天气曲线、3 个高光时刻、常出现的人 / 去过的地方、月度叙事、给下个月的一句话；可导出分享长图

### 8. 记忆
- 小局眼中的你：画像摘要 + 性格标签，可手动刷新
- 文风指纹：平均句长、口头禅、句尾语气词、感叹 / 省略比例、高频词、代表性原句
- 关系图谱：力导向图，节点大小代表出现频次，点击跳转到相关胶囊
- 全部记忆：按类型筛选，显示被想起次数、到期状态，可编辑、可删除

### 9. 演示
- 示例人生「林小满」：在杭州做设计师的半年，含大理旅行、妈妈、好友、胶片摄影、认证考试、近期工作压力等完整故事线。所有时间都相对真实的今天计算，不需要快进。
  - 刚载入：最近一周情绪低落 → 小局来信安慰；半年前写给未来自己的信今天送达。
  - 收件人「小鹿」有一组往来信件，小满昨晚写给她的信，回信正在路上。
  - 之后几天：大理旅行刚满三个月、认证考试昨天到期，小局会陆续来信。

### 10. 设置与数据
- 修改称呼；查看各 AI 能力的配置状态
- 载入 / 清空示例数据；一键导出全部数据（JSON）
- 「它是怎么工作的」架构说明页

## 五、有价值的技术点

### 1. 分层长期记忆
原始记录 → LLM 结构化抽取 → 向量 + 实体图谱 → 持续演化的用户画像。让 AI 真正「越用越懂你」，而不是每次对话从零开始。
代码：`src/lib/memory/extract.ts`、`src/lib/memory/profile.ts`

### 2. 混合记忆检索（参考 Generative Agents）
```
score = 1.0·语义相似 + 0.35·时间衰减(半衰期45天) + 0.45·重要度 + 0.5·实体重合
```
再用 MMR（最大边际相关）去重，避免相似记忆挤满上下文。回顾往事时切换为「怀旧权重」，弱化新近性、强化重要度。每次被检索会累计 `recallCount`。
代码：`src/lib/memory/rank.ts`、`src/lib/memory/retrieve.ts`

### 3. 主动式 AI：小局来信与代笔回信
从「用户问、AI 答」变为「AI 在合适的时候主动来信」。纯函数触发器（易测试）→ 优先级排序 → 20 小时频控 → 去重键防止重复 → 检索 → 生成 → 自检 → 投递。你寄给虚拟收件人的信，在 2~24 小时后由代笔引擎回信：检索 → 知识边界推理 → 以收件人身份写信 → 越界核查。
代码：`src/lib/postman/triggers.ts`、`src/lib/postman/engine.ts`、`src/lib/postman/reply.ts`

### 4. 个性化口吻：文风指纹
本地统计用户的句长、口头禅、语气词、标点习惯和代表性原句，转成写作指令，让平行时空的你写信时像用户本人。平行时空的你只能检索到分岔点之前的记忆，保证时间线一致；代笔的「某个人」先经过知识边界推理，只用 TA 知道的事写信。
代码：`src/lib/memory/style.ts`

### 5. 防编造与可解释
- 信中引用的记忆 id 强校验，不存在的引用被剔除
- 接入真实模型时，再做一轮事实核查，发现无依据的说法自动改写
- 每封信公开触发原因与引用的回忆
- 用户可查看、修改、删除任何记忆，数据可完整导出

### 6. 可靠的结构化输出
LLM 输出 → 容错解析（代码块、前后废话、尾逗号、中文引号）→ zod 校验 → 失败时把错误反馈给模型修复重试 → 最终兜底。
代码：`src/lib/ai/json.ts`

### 7. 可插拔模型 + 优雅降级
对话 / 看图 / 向量 / 语音按角色独立配置，统一 OpenAI 兼容协议，可在 DeepSeek、通义千问、硅基流动等之间切换。任何一环未配置或失败都回退到本地实现：
- 对话 → 规则抽取器 + 模板写信器（会利用真实记忆和文风指纹，不是写死的台词）
- 看图 → EXIF + 用户文字
- 向量 → 本地中文 n-gram 哈希向量（零依赖、离线可用）

代码：`src/lib/ai/provider.ts`、`src/lib/ai/mock.ts`、`src/lib/memory/embed-lite.ts`、`src/lib/memory/heuristics.ts`

### 8. 流式交互与多模态采集
SSE 流式追问（先推送联想记忆元数据，再推送文本增量）；照片 EXIF 与离线逆地理编码；录音实时波形与语音转写；前端图片压缩。
代码：`src/app/api/entries/[id]/interview/route.ts`、`src/lib/geo.ts`、`src/components/record/`

### 9. 真实时间线
所有业务逻辑都通过统一的 `now()` 获取真实时间；胶囊、那个瞬间、分岔点只能选过去，写给未来的信只能送往未来，前后端都校验。
代码：`src/lib/clock.ts`、`src/lib/time-rules.ts`

## 七、已知限制

- 演示模式下信件与故事卡片由模板拼接，文笔不如真实大模型，正式展示建议接入 DeepSeek
- 规则抽取器对复杂句式的人名识别有限
- Web Speech API 在部分浏览器 / 网络环境下不可用，此时需配置服务端 ASR 或手动输入
- 当前为单用户本地应用，无账号体系
- 向量检索在内存中计算，适合个人数据量；数据量变大时可替换为 sqlite-vec
